# Smart File Organizer

A simple desktop application built with Python to organize files automatically, detect duplicate files, and manage folders with ease.

## ✨ Features

- **File Scanner:** Scan folders and view file statistics.
- **File Organizer:** Automatically organize files into categories.
- **Duplicate Finder:** Detect duplicate files using SHA-256 hashing.
- **Undo:** Restore files to their original locations.
- **Modern GUI:** Clean and user-friendly desktop interface.

## 🚀 Run from Source

1. Clone this repository:

```bash
git clone https://github.com/Miladjalilnia/SmartFileOrganizer.git
```

2. Open the project folder:

```bash
cd SmartFileOrganizer
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python main.py
```
